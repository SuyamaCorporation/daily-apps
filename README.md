## 累計

**50アプリ**（2日間・¥0コスト・完全 public OSS / MIT）

## 仕組み

毎日 **03:00 JST** に VM 上の自律エージェント（`app-factory.timer`）が:

1. ネット情報源（HN/Reddit/Product Hunt/GitHub Trending）から AIスコアリングで30案選定
2. 各案を独立 public repo として GitHub Pages 公開
3. 鈴木独立レビュー + 倫理ガード PASS
4. Slack 進捗逐次通知 + 集約報告
